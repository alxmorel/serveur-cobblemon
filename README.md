# Pokémon Minecraft Server

Projet de développement d'un serveur Minecraft Pokémon basé sur Cobblemon.

## Environnement

- Minecraft Java 1.21.1
- Fabric
- Cobblemon 1.8.1
- Java 21

## Structure

- `content/` — contenu du serveur
- `resourcepack/` — resource pack
- `datapack/` — datapacks
- `fabric-mod/` — mods Fabric personnalisés
- `map/` — maps et schematics
- `scripts/` — scripts de développement et déploiement
- `docs/` — documentation
